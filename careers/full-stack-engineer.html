About the Role

Vyomantra Technologies is growing its core product and solutions engineering team. We build scalable SaaS solutions (including StockMitra, our retail ERP & Billing engine) and bespoke platforms for international clients in hospitality, logistics, healthcare, and e-commerce.

As a Full-Stack Software Engineer, you will bridge the gap between design fidelity and robust systems infrastructure. You will architect database schemas, build high-speed APIs, craft modular UI component libraries, and oversee automated deployments to cloud environments.

Responsibilities

  • Architect, implement, and maintain responsive web applications using React, Next.js, and TypeScript.
  • Develop scalable backend APIs in Node.js (Express/Fastify) or Python (FastAPI/Django).
  • Design relational and document database schemas (PostgreSQL, MySQL, Redis, MongoDB).
  • Ensure high code quality through unit testing, integration tests, and rigorous pull request reviews.
  • Configure CI/CD pipelines, Docker containerization, and monitoring instrumentation.
  • Mentor junior developers and interns on best software practices and clean code design.

Eligibility & Requirements

Experience & Qualifications:

Bachelor’s degree in Computer Science, Information Technology, or equivalent practical industry experience (1–3+ years in full-stack web development).

Core Competencies:

  • Deep proficiency in JavaScript / TypeScript, modern React, state management, and SSR/SSG concepts.
  • Solid experience writing production APIs in either Node.js or Python.
  • Hands-on proficiency with relational databases (PostgreSQL or MySQL) and query optimization.
  • Familiarity with containerization (Docker) and basic Linux server administration.
