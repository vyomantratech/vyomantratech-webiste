About the Opportunity

Behind every seamless user experience lies a robust, fault-tolerant backend. At Vyomantra Technologies, our backend engineers build the foundational data layers that power enterprise inventory software (StockMitra), high-volume hotel booking engines, and AI lead scoring platforms.

As a Python & Backend Engineering Intern, you will transition from writing standalone scripts to architecting asynchronous APIs, database connection pools, caching layers, and background worker queues. You will gain hands-on experience with modern cloud tools and receive direct code reviews from experienced systems architects.

Key Responsibilities

  • Design and implement clean, high-performance RESTful APIs using Python (FastAPI / Flask).
  • Write and optimize SQL queries, migrations, and schema indexes for PostgreSQL and MySQL databases.
  • Implement token-based authentication (JWT), role-based access control (RBAC), and payload validation.
  • Work with Redis for caching, rate limiting, and asynchronous background worker queues.
  • Integrate external APIs, payment gateways (Razorpay/Stripe), SMS/WhatsApp gateways, and webhook listeners.
  • Explore vector databases (ChromaDB / Pinecone) and LLM tool execution pipelines under mentor guidance.

Eligibility & Requirements

Educational Eligibility:

Students currently pursuing or recently graduated with a degree in B.E / B.Tech (CSE, IT, ECE), MCA, M.Sc / B.Sc (Computer Science), or developers with demonstrable backend projects.

Technical Prerequisites:

  • Solid foundation in Core Python (OOP concepts, data structures, exception handling, decorators).
  • Understanding of relational database design, basic normalization, and SQL CRUD queries.
  • Basic knowledge of HTTP protocol, status codes, request methods (GET, POST, PUT, DELETE), and JSON.
  • Basic Git commands (commit, branch, push, pull).

Bonus Skills:

Prior exposure to FastAPI, Docker containers, Postman API testing, or Linux server commands will give you an added edge.
