1. EXECUTIVE SUMMARY
================================================================================
Batch 2 has achieved complete harmonization of all SEO canonical tags, internal
website links, dynamic URL generators, and host domain references across the
entire Vyomantra Technologies production codebase.

Prior to this batch, 95.5% of canonical tags referenced legacy `.html` file paths,
over 2,550 internal navigation links forced users and search engine crawlers
through `.html` redirects, and JavaScript modules dynamically generated `.html`
career subpage links.

In Batch 2:
1. 100% of public canonical tags (45 total across all HTML pages and template
   generators) have been updated to clean, extensionless, non-www HTTPS URLs.
2. 2,544 internal navigation, header, dropdown, footer, card, and CTA button links
   were converted from legacy `.html` links to clean, root-relative URLs.
3. Dynamic careers URL generation across public listings, admin dashboards, and
   the server-side subpage builder was converted to `/careers/${slug}`.
4. Dynamic course architecture was thoroughly audited, confirming courses render
   in-place on `/courses` without orphan or unindexed subpages.
5. All internal `www.vyomantratech.com` references in legal and policy pages were
   normalized to `https://vyomantratech.com`.
6. Zero visual styles, CSS layouts, metadata schemas, tracking scripts, or Batch 1
   server routing rules were disturbed.

The entire URL flow now strictly satisfies the architectural objective:
Clean Browser URL -> Direct HTTP 200 -> Self-Referencing Canonical -> Clean Internal Links -> Clean Sitemap.

  Job postings are stored in the database (`job_postings` table) and mirrored to
  `data/jobs.json`. When a new role is published or updated via the admin portal,
  `api/admin/job-builder.php` generates a physical leaf file at `careers/{slug}.html`.
  Server-side routing (`.htaccess` Rule 7) intercepts `/careers/{slug}` and internally
  rewrites it to `careers/{slug}.html`.

- Current URL Generation (Before):
  * Dynamic job cards generated `href="careers/${j.slug}.html"`
  * Admin API returned `subpage_url = 'careers/' . $slug . '.html'`

  * Generated subpage had canonical tag pointing to `careers/{$slug}.html`

    legacy `.html` extensions automatically from older database rows.
  * `admin/js/admin.js`: Saves new/updated jobs with `subpage_url: '/careers/' + slug`.
    Table links point to `/careers/${j.slug}` with target `_blank`.
  * `api/get-jobs.php`: Injects `$r['subpage_url'] = '/careers/' . $r['slug']`.
  * `api/admin/jobs.php`: Injects and updates `subpage_url = '/careers/' . $slug`.
  * `api/admin/job-builder.php`: Emits canonical `<link rel="canonical" href="https://vyomantratech.com/careers/{$slug}">`
    and all template navigation/footer links as clean root-relative paths (`/`, `/services`, etc.).
